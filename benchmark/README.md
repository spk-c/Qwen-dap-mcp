# Benchmarks

Performance benchmarks have not been re-established for this fork. Existing GitHub Actions test jobs verify correctness, not latency, debugger throughput, peak resident memory, or high-concurrency stability.

Any future benchmark must record the adapter/version, OS, CPU, target binary, toolset and security profile, sample count, median/p95 latency, source commit, and the number of test failures. Do not present mock-adapter timings as real debugger performance.
